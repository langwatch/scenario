# Observability

This recipe documents the hooks and result fields that let you instrument a voice scenario
for offline review, performance measurement, and debugging without modifying your agent.

## Pattern

### Hooks

Register `on_audio_chunk` / `onAudioChunk` and `on_voice_event` / `onVoiceEvent`
callbacks on `scenario.run()` (in Go, `OnAudioChunk` and `OnVoiceEvent` on the
`voice.Config` passed to `scenario.Run` with `voice.WithConfig`):

:::code-group

```python [python]
from scenario.voice import AudioChunk, VoiceEvent

audio_chunks: list[AudioChunk] = []
voice_events: list[VoiceEvent] = []

def on_audio_chunk(chunk: AudioChunk) -> None:
    audio_chunks.append(chunk)

def on_voice_event(event: VoiceEvent) -> None:
    print(f"[voice_event] {event.type} @ {event.time:.3f}s")
    voice_events.append(event)

result = await scenario.run(
    name="my_scenario",
    ...
    on_audio_chunk=on_audio_chunk,
    on_voice_event=on_voice_event,
)
```

```typescript [typescript]
import scenario, { voice } from "@langwatch/scenario";

const audioChunks: voice.AudioChunk[] = [];
const voiceEvents: voice.VoiceEvent[] = [];

const result = await scenario.run({
  name: "my_scenario",
  // ...agents, script...
  onAudioChunk: (chunk) => {
    audioChunks.push(chunk);
  },
  onVoiceEvent: (event) => {
    console.log(`[voice_event] ${event.type} @ ${event.time.toFixed(3)}s`);
    voiceEvents.push(event);
  },
});
```

```go [go]
import (
	"fmt"

	scenario "github.com/langwatch/scenario/go"
	"github.com/langwatch/scenario/go/voice"
)

var audioChunks []voice.AudioChunk
var voiceEvents []voice.VoiceEvent

result, err := scenario.Run(ctx, scenario.ScenarioConfig{
	Name: "my_scenario",
	// ...Agents, Script...
}, voice.WithConfig(voice.Config{
	OnAudioChunk: func(chunk voice.AudioChunk) {
		audioChunks = append(audioChunks, chunk)
	},
	OnVoiceEvent: func(event voice.VoiceEvent) {
		fmt.Printf("[voice_event] %s @ %.3fs\n", event.Type, event.Time)
		voiceEvents = append(voiceEvents, event)
	},
}))
```

:::

`onAudioChunk` fires for every raw PCM16 audio chunk that flows through the pipeline.
`onVoiceEvent` fires for higher-level events (turn start, turn end, VAD detection, etc.)
and includes a wall-clock timestamp at `event.time`. (In Go, `event.Time` is the
position on the recorded audio, in seconds from the scenario start.)

### Saving the conversation audio

After the run, call `result.audio.save(path)` to write the conversation audio to disk
(in Go, `voice.ResultOf(result).Recording.Save(ctx, path, "")`):

:::code-group

```python [python]
if result.audio is not None:
    result.audio.save("recordings/my_scenario.wav")
```

```typescript [typescript]
if (result.audio) {
  result.audio.save("recordings/my_scenario.wav");
  // WAV is written natively; .mp3/.ogg/.flac transcode via the system ffmpeg.
}
```

```go [go]
if vr := voice.ResultOf(result); vr != nil && vr.Recording != nil {
	// WAV is written natively; .mp3/.ogg/.flac transcode via the system ffmpeg.
	if _, err := vr.Recording.Save(ctx, "recordings/my_scenario.wav", ""); err != nil {
		t.Fatal(err)
	}
}
```

:::

<Callout type="info">
`result.audio` is `None` / `undefined` when no audio turns were recorded (e.g. the
adapter disconnected before any exchange). Always guard before reading it
(`if result.audio is not None` / `if (result.audio)`). In Go, `voice.ResultOf`
returns `nil` for a run with no voice agent; check it and its `Recording` before use.
</Callout>

### Latency metrics

`result.latency` exposes a `LatencyMetrics` object. Field names are `snake_case`
in Python and `camelCase` in TypeScript. In Go it is `voice.ResultOf(result).Latency`,
with `*float64` fields that are `nil` when not measurable:

| Python | TypeScript | Go | Description |
|---|---|---|---|
| `time_to_first_byte` | `timeToFirstByte` | `TimeToFirstByte` | Wall-clock seconds from when the user turn ended to when the first byte of agent audio arrived. |
| `avg_response_time` | `avgResponseTime` | `AvgResponseTime` | Mean agent response time across all turns. |
| `p50_response_time` | `p50ResponseTime` | `P50ResponseTime` | Median agent response time across all turns. |
| `p95_response_time` | `p95ResponseTime` | `P95ResponseTime` | 95th-percentile agent response time across all turns. |
| `interrupt_response_time` | `interruptResponseTime` | `InterruptResponseTime` | Time from interrupt signal to agent resume (populated only when `interrupt` was used). |

:::code-group

```python [python]
if result.latency is not None:
    print(f"TTFB: {result.latency.time_to_first_byte:.3f}s")
    print(f"avg:  {result.latency.avg_response_time:.3f}s")
    print(f"p50:  {result.latency.p50_response_time:.3f}s")
    print(f"p95:  {result.latency.p95_response_time:.3f}s")
```

```typescript [typescript]
if (result.latency) {
  console.log(`TTFB: ${result.latency.timeToFirstByte?.toFixed(3)}s`);
  console.log(`avg:  ${result.latency.avgResponseTime?.toFixed(3)}s`);
  console.log(`p50:  ${result.latency.p50ResponseTime?.toFixed(3)}s`);
  console.log(`p95:  ${result.latency.p95ResponseTime?.toFixed(3)}s`);
}
```

```go [go]
if vr := voice.ResultOf(result); vr != nil && vr.Latency != nil {
	show := func(label string, v *float64) {
		if v != nil {
			fmt.Printf("%s %.3fs\n", label, *v)
		}
	}
	show("TTFB:", vr.Latency.TimeToFirstByte)
	show("avg: ", vr.Latency.AvgResponseTime)
	show("p50: ", vr.Latency.P50ResponseTime)
	show("p95: ", vr.Latency.P95ResponseTime)
}
```

:::

<Callout type="warning">
`result.latency` is `None` / `undefined` (`nil` in Go) when no agent audio turns were recorded.
Guard before reading its fields, especially in CI — a latency pipeline regression
will silently report a missing value rather than fail otherwise.
</Callout>
