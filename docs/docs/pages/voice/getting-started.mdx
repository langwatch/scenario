# Voice Agents — Getting Started

Test voice agents end-to-end with the same `scenario.run()` API you use for text.
Pick a `VoiceAgentAdapter` for your provider, describe what the agent should do,
and let the simulator drive a voice conversation over real audio.

## Install

```bash
pip install "langwatch-scenario[voice]"
```

## Required env vars

| Variable | Required | Purpose |
|---|---|---|
| `OPENAI_API_KEY` | Yes | UserSimulatorAgent TTS + JudgeAgent LLM |
| `PIPECAT_BOT_URL` | No | Override the default `ws://localhost:8765/stream` |

Set `OPENAI_API_KEY` in `python/.env` or export it in your shell before running.

## Your first voice scenario

The snippet below uses `PipecatAgentAdapter` with the bundled stub bot — no extra
services needed. `ensure_pipecat_bot()` auto-spawns the stub on `:8765` when you
run the script and tears it down on exit.

<GettingStartedExample />

Save this as `getting_started.py` and run it:

```bash
cd python
uv run examples/voice/getting_started.py
```

You should see:

```
success: True
verdict: The bot responded to the user in a friendly tone ...
```
