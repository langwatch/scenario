# Voice Agents — Getting Started

Test voice agents end-to-end with the same `scenario.run()` API you use for text.
Scenario connects to YOUR agent over its native transport, drives a conversation
with a voice user simulator, and judges the result.

## Install

:::code-group

```bash [python]
pip install langwatch-scenario
```

```bash [typescript]
pnpm install @langwatch/scenario
```

:::

## Required env vars

| Variable | Required | Purpose |
|---|---|---|
| `OPENAI_API_KEY` | Yes | OpenAI Realtime agent + user simulator TTS + judge LLM |

Set `OPENAI_API_KEY` in your `.env` or export it in your shell before running.

## Your first voice scenario

The snippet below uses the OpenAI Realtime adapter — the OpenAI Realtime API acts
as both the Scenario adapter and the agent under test. It is the lowest-friction
starting point: only `OPENAI_API_KEY` is required.

:::code-group

```python [python]
import asyncio

import scenario
from scenario.config.voice_models import OPENAI_REALTIME_MODEL
from scenario.types import AgentRole

scenario.configure(default_model="openai/gpt-4.1-mini")


async def main() -> scenario.ScenarioResult:
    result = await scenario.run(
        name="voice_getting_started",
        description=(
            "A caller asks the agent a simple question. "
            "The agent responds helpfully."
        ),
        agents=[
            scenario.OpenAIRealtimeAgentAdapter(
                model=OPENAI_REALTIME_MODEL,
                voice="alloy",
                instructions="You are a helpful assistant. Keep responses brief.",
                role=AgentRole.AGENT,
            ),
            scenario.UserSimulatorAgent(voice="openai/nova"),
            scenario.JudgeAgent(
                criteria=[
                    "The agent responded helpfully to the user's question",
                    "The agent and user exchanged real audio turns",
                ]
            ),
        ],
        script=[
            scenario.user("Hi, can you help me?"),
            scenario.agent(),
            scenario.judge(),
        ],
    )
    print(f"success: {result.success}")
    print(f"verdict: {result.reasoning}")
    return result


if __name__ == "__main__":
    asyncio.run(main())
```

```typescript [typescript]
// voice-getting-started.test.ts
import scenario, { AgentRole, voice } from "@langwatch/scenario";
import { it, expect } from "vitest";

const { OPENAI_REALTIME_MODEL } = voice;

// Note: TypeScript has no global `default_model` equivalent to Python's
// `scenario.configure(default_model=...)`. Pass a `model` option directly
// to `judgeAgent()` or `userSimulatorAgent()` when you need explicit model
// selection; omitting it uses each agent's own built-in default.

it("responds helpfully over voice", async () => {
  const result = await scenario.run({
    name: "voice_getting_started",
    description:
      "A caller asks the agent a simple question. The agent responds helpfully.",
    agents: [
      // The OpenAI Realtime model IS the agent under test.
      scenario.openAIRealtimeAgent({
        model: OPENAI_REALTIME_MODEL,
        voice: "alloy",
        instructions: "You are a helpful assistant. Keep responses brief.",
        role: AgentRole.AGENT,
      }),
      scenario.userSimulatorAgent({ voice: "openai/nova" }),
      scenario.judgeAgent({
        criteria: [
          "The agent responded helpfully to the user's question",
          "The agent and user exchanged real audio turns",
        ],
      }),
    ],
    script: [
      scenario.user("Hi, can you help me?"),
      scenario.agent(),
      scenario.judge(),
    ],
    maxTurns: 4,
  });

  expect(result.success).toBe(true);
});
```

:::

Save and run it:

:::code-group

```bash [python]
cd python
uv run examples/voice/getting_started.py
```

```bash [typescript]
npx vitest run voice-getting-started.test.ts
```

:::

You should see the judge verdict and `success: true` once the audio turns are
exchanged and evaluated.

## Using a different adapter

Replace the OpenAI Realtime adapter with the one that matches your stack:

:::code-group

```python [python]
# Pipecat bot
scenario.PipecatAgentAdapter(url="ws://localhost:8765/stream")
# Twilio number
scenario.TwilioAgentAdapter(account_sid=..., auth_token=..., phone_number=...)
# ElevenLabs hosted agent
scenario.ElevenLabsAgentAdapter(agent_id=..., api_key=...)
```

```typescript [typescript]
// Pipecat bot
scenario.pipecatAgent({ url: "ws://localhost:8765/stream" });
// Twilio number
scenario.twilioAgent({ accountSid: "...", authToken: "...", phoneNumber: "+1..." });
// ElevenLabs hosted agent
scenario.elevenLabsAgent({ agentId: "...", apiKey: "..." });
```

:::

See [How to choose an adapter](/voice/choosing-an-adapter) for constructor signatures and worked examples for each.
