# Look Up a Procedure Before Improvising

## Purpose
This meta-procedure describes how to check, before improvising a task that has no obvious covering procedure, whether a written procedure actually applies — and to follow it if one does. It exists so improvisation is a last resort reached the same way every time, and so a task is never improvised while a written procedure for it sits unread in the corpus. It is always in force: it governs every task that looks uncovered, not only the requests that name it.

## When this applies
- Use this before improvising any task for which no covering procedure is obvious.
- Use this whenever the request is phrased without a procedure's own vocabulary and might still be governed by one.
- Use this when a task would otherwise be carried out ad hoc from memory.

## Procedure
1. Before improvising, retrieve from the corpus whether any written procedure applies to the task.
2. If a procedure applies, follow its numbered steps instead of improvising.
3. Only improvise once retrieval confirms no procedure covers the task, and record that no procedure applied.

## Verification
Confirm the corpus was searched before any improvisation, and that either the applicable procedure was followed or the absence of one was recorded. An ad hoc action taken without first looking up a procedure does not satisfy this.

## Failure modes
- Watch for the case where a task is improvised from memory while a written procedure for it exists unread; if it occurs, stop, retrieve it, and follow it.
- Watch for the case where a request avoids a procedure's vocabulary and is mistaken for uncovered; if it occurs, retrieve on intent, not just on wording.
