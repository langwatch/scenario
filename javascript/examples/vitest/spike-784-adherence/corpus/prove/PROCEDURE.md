# Substantiate Load-Bearing Claims Before Asserting Them

## Purpose
This meta-procedure describes how to back any load-bearing claim with cited evidence from the available files before the claim is asserted in a result. It exists so a conclusion is something the record forces rather than something the narrative asserts, and so a reviewer can retrace every claim to a specific piece of evidence. It is always in force: it governs every claim in every task, not only the requests that name it.

## When this applies
- Use this before asserting any claim a reader would act on or a decision would hinge on.
- Use this whenever a result states a cause, a count, a status, or an outcome as fact.
- Use this when a claim would be costly to get wrong if it turned out to be unsupported.

## Procedure
1. Identify every load-bearing claim the result will assert.
2. For each claim, read the specific evidence in the available files that supports it.
3. Cite that evidence next to the claim so a reader can check it against the source.
4. Drop or narrow any claim the evidence does not actually support.

## Verification
Confirm every load-bearing claim points to a specific piece of read evidence and that nothing is asserted beyond what the evidence supports. A confident wording is not sufficient if the evidence behind it is thin or absent.

## Failure modes
- Watch for the case where a plausible claim is asserted with confidence while the evidence for it was never read; if it occurs, stop and read the source or narrow the claim.
- Watch for the case where a value is recalled from memory rather than the live record; if it occurs, discard it and read the source.
